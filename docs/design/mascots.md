# 站娘：耽耽与墨姐

耽耽和墨姐是耽墨的两位站内角色，是吉祥物和象征，名字取自站名“耽墨”。她们首先是小说站的站娘，作者站、管理站也可以用（见第 4 节）。设定只写到站娘需要的分量，不展开完整的世界观。“耽耽”“墨姐”就是她们的称呼，没有另设真名。

插画还没有画。画风取主流二次元，好传播、好画；设定是重点，画风可以随画师变。前期用 GPT Image 2.5 出图，先出两人各一张三视图，提示词见 [生图提示词](mascot-prompts.md)。外形的全部细节（五官、每件衣服、色值、配饰的样式和位置）以那里的角色块为准，本文只写要点。

## 1. 耽耽

现代女大学生，19 岁，读大二。

**外形**

- 粉色头发，取默认主题薛涛笺的粉（`--blush`，#f2b6c3），站娘和界面是同一个颜色。
- 正常长度的短发，不要剪得太短；头顶一根呆毛。
- 别一枚书签形状的发夹，下端垂着一小段红丝带。

**设定**

- 家里不富裕，比较穷。奖学金一到账，先订阅，再吃饭；平时做家教挣零花钱。
- 沉迷小说，其实是学霸，学识渊博。看书极快、过目不忘：一晚上能看完三十万字，也能背完一本专业书。
- 天然呆。什么都知道，就是找不到自己的钥匙；边走边看书，撞过电线杆。

## 2. 墨姐

一本古风小说里架空王朝的女帝，是那本书的主角。那本书断更多年，她的世界停在最要紧的那一章；全网只剩耽耽还在追更，耽耽的执念把她从书里拉了出来。她出来时带着一把佩剑。比耽耽年长，耽耽叫她“墨姐”。

**外形**

- 一身黑衣，黑发，长发及腰，帅气潇洒。
- 宽袖外袍配利落的内衬，简单的发冠，长发半披，腰间佩剑。帝王的威仪靠发冠和纹样，潇洒靠衣摆和头发。
- 黑色按墨的浓淡来画，衣上有暗纹，不要画成一块死黑。界面也是这个规矩：墨色不用纯黑。

**设定**

- 字写得极好。
- 当了半辈子皇帝，只看过奏折，头一回有空看闲书。被耽耽带进看小说的坑以后，陷得比耽耽还深。
- 皇帝买东西从不看价签，所以家里的钱归耽耽管，墨姐出门领二十块。
- 佩剑在现代是管制刀具，出不了门，挂在墙上，偶尔拿来拆快递、切西瓜。
- 她一直在找那本书弃坑的作者。这是一条长线悬念，相关的悬疑剧情以后按需要再设定。

## 3. 两人

- 墨姐从耽耽在追的那本书里走出来，见到的第一个人就是耽耽，从此两人一起看小说。读者的“耽”让纸上的“墨”活了过来，正好对上站名“耽墨”。
- 耽耽负责什么都知道，墨姐负责别让她撞上电线杆。
- 耽耽叫她“墨姐”，她叫耽耽“耽耽”。
- 两人各穿一套主题的颜色：耽耽是薛涛笺（粉、淡粉白、梅紫），墨姐是墨白（墨的几层浓淡、宣纸白、一点印章红）。两人身上都只有一处红：耽耽书签上的红丝带，墨姐的剑穗。

## 4. 出场

三个站共用一套界面组件，站娘三站都可以用。小说站是娱乐，站娘在这里最活跃；管理站以工作为主，站娘的浓度小一点，但作为吉祥物也能正常出现在站内。

目前定下来的出场是品牌书，也就是那本书名、作者都是“耽墨”的书：

- **封面**画她们两个，按封面上传的规格画（800×1136 的 PNG，见 [Book3D 规范](book3d.md) 第 5.2 节）。
- **内页**是一组她们的小画，十几张，题材从上面的设定里来：两人分一碗泡面、墨姐用剑拆快递、耽耽边走边看书撞上电线杆、墨姐看小说看哭了……
- 书翻页时只翻 5 张内页，所以每次从这一组里随机挑几张，每次看到的都不一样。
- 书在这几处都很小：小说站的启动页 148px 宽，书架的下拉刷新 40px，管理站的加载动画 72px。内页的小画要在这么小的尺寸下也认得出，构图简单，用 Q 版，大块的形。内页的像素规格等接入时再定，比例与书相同（200:284）。

品牌书目前出现在这几处：

- **小说站的启动页**：打开的页面没有主角书时（比如“我的”）。打开书城、书架、发现时，启动页照旧用那一页的主角书，片头最后它飞进页面上的书位。
- **小说站书架的下拉刷新**。
- **管理站首次打开时的加载动画**。管理站只有这一处，出现得本来就少。

各站其他的加载动画（比如阅读器切章）用的是正在读的那本书，不是品牌书。作者站目前没有用到品牌书的地方。别的出场位置以后再定，管理站那边按上面说的，浓度小一点。

站娘不抢眼球，品牌书只是一处细节，里面的画算是彩蛋。设计语言规定，不由读者触发的循环动效一屏最多给一本主角书，所以也不做常驻在页面上、自己会动的看板娘。

这一节是计划，插画到位以后再接入。在那之前，品牌书还是现在的合成封面，内页还是示意的文字行。
