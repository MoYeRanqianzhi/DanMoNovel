# 设计语言

耽墨的小说站、作者站、管理站用同一套设计语言：同一套令牌、同一组主题、同一本 3D 书。三站可以各有特色，但不能像三个毫不相干的网站。

令牌的源文件在 `packages/design/src/styles/`：`tokens.css` 放尺寸、字体、字号、圆角、缓动与时长，`themes.css` 放各主题的颜色。改令牌时请同步修改本文。

## 1. 方向

界面要柔和、新颖、看着舒适。默认是淡粉色，另有护眼、夜间和几套彩色主题。设计不要死板，要有想象力。

耽墨想避开“模板化的粉色阅读 App”。所以不用玻璃拟态、渐变光斑和满屏粒子，而是从纸、墨、书、印章这些实物里找语言。

## 2. 五个母题

1. **书是主角。** 每本书都是同一个 CSS 3D 书本组件（Book3D）。点开一本书，它从列表飞进详情页；开始阅读时，书打开、推进到铺满屏幕，正文就在翻开的书页上；加载动画也是这本书在翻页。详见 [Book3D 规范](book3d.md)。
2. **红线只承载信息。** 红线色（`--thread`）只用在阅读进度、CP 配对、当前位置、焦点环和“选中的是哪一项”上，不用来装饰。想加一处红色之前，先问它表达了什么信息。
3. **纸与墨。** 页面是纸色底加一层细细的纸纹，正文是墨色，不用纯黑。阴影随主题染色，不用统一的灰。
4. **动效回应操作。** 动效是对读者操作的回应。不由读者触发的循环动效，一屏最多给一本主角书（例如书架上缓缓漂浮的那本）。读者在系统或应用里选了“减少动效”时，必须照办，见第 7 节。
5. **安静，少说明。** 不在物件旁边写操作说明，而是让物件本身可以直接上手：点一下书就翻到封底，拖动可以转着看。键盘与读屏用户靠不可见的可访问名称得到同样的操作。写实的细节要克制，比例参照真书：封底的书号条码只占封底宽度的四分之一左右。

## 3. 三站：同一套语言，各有特色

| 站点 | 默认主题 | 母题 | 特色元素 |
|---|---|---|---|
| 小说站（读者） | 薛涛笺 | 读者的书架与书页 | 书城的书环、书架的四种摆法、阅读器的十种纸张、印章记录的阅读时长 |
| 作者站（作者） | 缃叶 | 文房 | 砚台（今日字数）、方格稿纸、毛笔墨迹画成的数据图、信笺样式的读者来信、条幅名帖与闲章 |
| 管理站（运营团队） | 墨白 | 书局的编辑部，批阅 | 朱批与浮签、盖下去的“准”“退”二印、只能追加的账簿、每种身份一方印 |

三站默认主题不同，工作人员一眼就能分清自己在哪个站；八套主题在每个站都可以选。

三站共用的部分放在 `packages/design`：令牌与主题、Book3D、飞行过渡、页面栈、印章（Seal）与盖章（Stamp）、底部面板（Sheet）、轻提示（Toast）、分段控件（Segmented）、选项卡片（ChoiceCards）、设置列表、稿纸（Manuscript）、远山图（Hills）。一个组件至少两个站要用，或者属于母题，才放进共享包。

## 4. 颜色与主题

### 4.1 八套主题

| 名称 | 类别 | 说明 |
|---|---|---|
| 薛涛笺 | 默认 | 淡粉色的笺纸。唐代薛涛自制的小幅粉笺，是这套主题名字的来历 |
| 长夜 | 夜间 | 深紫夜色，关灯后读不刺眼；正文不用纯白 |
| 豆青 | 护眼 | 低饱和的豆绿，久读不累眼 |
| 缃叶 | 护眼 | 旧书页的暖黄，最像纸质书；作者站默认 |
| 天青 | 彩色 | 雨过天青的浅蓝 |
| 紫藤 | 彩色 | 紫藤花的淡紫 |
| 盐汽水 | 彩色 | 薄荷绿，夏天的教室 |
| 墨白 | 彩色 | 宣纸与墨，只留一点印章红；管理站默认 |

### 4.2 每套主题都要定义的颜色

| 变量 | 用途 |
|---|---|
| `--paper` | 页面底色 |
| `--sheet` | 浮起的纸面：导航条、面板、按钮 |
| `--sheet-2` | 凹下的纸面：输入框、分段控件的底 |
| `--ink` | 正文墨色，永远不用纯黑 |
| `--ink-2` | 次要文字，对 `--paper` 的对比度不低于 4.5 |
| `--line` | 分隔线与描边（带透明度） |
| `--blush` / `--blush-ink` | 主色的大面积柔和填充（主按钮、选中态），以及填充上的文字 |
| `--thread` / `--thread-ink` | 红线，以及红线色的文字（加深到对比度不低于 4.5） |
| `--shadow-rgb` | 阴影色，让阴影随主题染色 |
| `--grain` | 纸纹 |
| `--reader-paper` / `--reader-ink` | 阅读页的纸色与正文色 |
| `--page` / `--page-line` | 3D 书内页的纸色与示意文字行的颜色 |
| `--scrim` | 面板遮罩 |

规则：

- 新增主题必须把上表的变量全部定义，否则会从外层主题“漏色”。改完运行 `pnpm check:contrast`，八套主题都要达标。
- 主题挂在 `data-theme` 属性上，任何元素都可以设。主题页的每张色样各自带 `data-theme`，所以不用另写预览代码就能看到这套配色。
- 读者换主题时，新配色从点按的位置像墨一样晕开（View Transition 加上注册过的 `--ink-r`）；减少动效时直接换。
- 公开页面的 HTML 要能被 CDN 缓存，所以服务端不按读者的偏好渲染。`<head>` 里的一小段脚本在页面绘制前读出本机保存的主题，写好 `data-theme`，刷新时不会先闪一下默认配色。

## 5. 字体与文字

### 5.1 界面字体

| 字体 | 用在哪里 |
|---|---|
| 霞鹜文楷屏幕阅读版 | 标题与正文，界面的“性格” |
| 系统无衬线 | 控件与数字 |
| 马善政毛笔楷书 | 只用于 Logo 与线装书的题签 |
| 思源宋体（400、700） | 现代装帧的封面书名，以及阅读字体选项 |

这几款都以 SIL Open Font License 1.1 授权，按 unicode-range 切片成网页字体，浏览器只下载页面上真正用到的字所在的分片。读者在阅读器里选的阅读字体是另一回事，见 [阅读器与内容保护](reader.md)。

### 5.2 字号

字号取自《排版的元素》的经典序列：12、14、16、18、21、24、36、48、72（`--fs-12` 到 `--fs-72`）。3D 书上的字按 200×284 的基准排版再整体缩放，所以基准下的字号不能小于 12px，否则中文环境浏览器的“最小字号”会把它撑大。

### 5.3 文案

- **面向读者命名。** 设置项、视图、格式的名字说“读者看到什么”，不说实现层面的东西。例如书架的四种摆法叫“陈列、书柜、宫格、列表”，不叫“封面视图、书脊视图”。
- 界面文字的引号用弯引号“”。数量词前写“两”，例如“两本”“两章”，不写“2 本”或“二本”。
- 作者站称呼作者一律用“你”，不用性别代词。
- 少说明：能让操作本身不言自明的，就不写操作提示。

## 6. 尺寸、间距与布局

| 令牌 | 值 |
|---|---|
| 间距 `--sp-1` 到 `--sp-12` | 4、8、12、16、20、24、32、40、48（4 的倍数） |
| 圆角 `--radius-s` | 6px：纸条类的小控件 |
| 圆角 `--radius-m` | 14px：浮起的纸面、卡片 |
| 圆角 `--radius-l` | 24px：底部面板 |
| 圆角 `--radius-pill` | 胶囊按钮 |
| 侧栏宽 `--rail-w` | 88px（电脑） |
| 底部导航高 `--tabbar-h` | 64px（手机，不含安全区） |
| 版心 `--content-max` | 1180px |

圆角按层级区分，而不是所有东西一个圆角。

**手机与电脑分别设计。** 两端的布局不同，不能把手机布局拉宽了事。

- 900px 及以上是宽屏：左侧出现侧栏，底部导航收起，页面换成多栏、更大的书、带悬停反馈的布局。书架与“我的”到 1100px 再分成左右两栏。
- 横放的手机（如 844×390）宽度不到 900，按窄屏排，但它只有三四百像素高。把插图吸在上半屏的版式，在矮屏上要改成左右两栏。
- 竖放的平板（768×1024）按窄屏排，要单独看一遍。
- 三站都开了 `viewport-fit=cover`，页面、导航、面板都要让开刘海与圆角（`--safe-top`、`--safe-bottom`、`--safe-left`、`--safe-right`）。
- 按输入方式适配：悬停倾斜只在精确指针（鼠标）下启用，长按选择只在触屏下启用。

## 7. 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ease-soft` | 快起慢收 | 大多数进入与响应，像纸落在桌面上 |
| `--ease-inout` | 对称 | 翻页、开合 |
| `--ease-spring` | 约 2% 的轻微回弹 | 书本落位、导航丝带 |
| `--dur-quick` | 180ms | 颜色、描边这类小变化 |
| `--dur-base` | 320ms | 页面进出、面板 |
| `--dur-slow` | 560ms | 大的位移 |

书的飞行有自己的时长：书位到书位 760ms，开书推进 1500ms，从阅读器回到书位 1300ms。

规则：

- **按时间算，不按帧算。** 用 requestAnimationFrame 驱动的动画，按经过的时间推进。按帧推进的话，在 120Hz、165Hz 的屏幕上会快一两倍。
- **减少动效。** “我的”里有“动效”一项：跟随系统、完整、减少。结果写在 `<html data-motion>` 上。减少时书不起飞、换主题不晕墨、启动页缩短；其余的动画与过渡都缩成一瞬间（连延迟一起清掉），印章直接显示盖好的样子。
- **注册过的变量。** `tokens.css` 用 `@property` 注册了 `--rx --ry --rz --tilt-x --tilt-y --spin --open --lift --leaf --lines --ink-r`。它们带类型、全局生效，是 3D 书的“骨骼”，动画靠它们插值。别的地方不要拿这些名字存别的类型的值，否则整条声明会静默失效。

## 8. 组件的几条约定

- **图标按钮**必须有可读的名字（`label`），它同时是读屏名称和悬停提示。
- **印章 Seal**：白文是满底朱红、字留白；朱文是红字红边。闲章、Logo 上的站名、身份印都用它。**盖章 Stamp** 是印章落下、印泥洇开的那一下，用来表示“决定已经作出”（提交审核、通过、退回），盖章本身就是反馈，不再另弹“提交成功”。
- **底部面板 Sheet**：手机上从底部升起，宽屏上是居中的纸卡（阅读器里贴着下栏）。打开时焦点移进面板，Esc 关闭后焦点回到打开它的按钮。
- **分段控件 Segmented** 用于两到四个互斥的短选项；选项多、需要示意图时用**选项卡片 ChoiceCards**（书架的摆法、翻页方式、稿纸）。
- **红线进度 ThreadProgress**：进度条就是一根红线，读屏读出百分比。

## 9. 层级表

页面之间没有 z-index，靠 DOM 顺序叠放：后进栈的页面在上。共享层的层级如下：

| 层 | z-index | 位置 |
|---|---|---|
| 页面 | 无（DOM 顺序） | `.screen` |
| 二级页顶栏、详情页操作栏 | 5 | `layout.css` 的 `.subbar`，小说站详情页 |
| 阅读器工具栏 | 6 | 小说站阅读器 |
| 阅读器亮度遮罩 | 7 | 小说站阅读器（连工具栏一起压暗，不拦截点击） |
| 写作页顶栏 | 10 | 作者站写作页（稿纸里的印是 2、浮签是 3，只在稿纸内部叠放） |
| 底部导航、侧栏 | 30 | `nav.css` |
| 启动页 | 35 | 小说站（高于导航，低于飞行层） |
| 飞行覆盖层 | 40 | `flight.css` |
| 底部面板 | 50 | `overlays.css`（渲染在 body 下） |
| 轻提示 | 70 | `overlays.css`（渲染在 body 下） |

页面内部要用正的 z-index 时，先在页面的容器上设 `isolation: isolate`，把层级关在页面里，免得盖住导航或面板。
