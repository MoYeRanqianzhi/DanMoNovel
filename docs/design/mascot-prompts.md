# 站娘生图提示词

给站娘耽耽、墨姐（见 [设定稿](mascots.md)）出图用的提示词。前期为了省钱，用 OpenAI 的 GPT Image 2.5 出图。两人的三视图已经定稿，存在 [mascots/](mascots/)（`dandan-turnaround.png`、`mojie-turnaround.png`）；立绘、Q 版三视图都以它们为参考图。

写法依据 OpenAI 的 [图像提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)（GPT Image 2.5 一栏）和 [图像生成文档](https://developers.openai.com/api/docs/guides/image-generation)。指南里和这里相关的几条：

- 先说要画什么图、做什么用，再写主体、构图、画风和限制；内容多时分成带标签的几段。
- 写清楚人物的取景、视线和手里拿着什么，比如“全身可见、连脚一起画进去”。
- 明确写出不要的东西，比如多余的文字、水印、Logo。
- 要让角色在多张图里保持一致，先做一张能反复用的角色参考图，以后每张图都带上它，并重复角色的关键特征。
- 一次只改一处；改图时写清“只改什么”和“哪些保持不变”。
- 尺寸、质量、背景放在 API 参数里，不写进提示词。

## 1. 模型与参数

| 参数 | 试提示词 | 出定稿 |
|---|---|---|
| `model` | `gpt-image-2.5-flare` | `gpt-image-2.5-sunburst` |
| `quality` | `medium` | `high` |
| `size` | `1536x1024` | `1536x1024`；脸和配饰看不清时用 `2304x1536` |
| `background` | `opaque` | `opaque` |
| `output_format` | `png` | `png` |
| `n` | `1` | `1` |

- 两款模型的 token 单价相同，与 GPT Image 2 一样：每百万 token 文本输入 $5、图片输入 $8、图片输出 $30。走 Batch 接口时图片输出半价（$15），代价是要排队等结果。官方没有给出每张图用多少 token，只能实际出几张看账单。
- Flare 快，画质与 GPT Image 2 相当；Sunburst 画质更好，官方推荐在改图精度最要紧时用它。三视图是以后所有图的参考，定稿用 Sunburst。
- `xhigh`、`max` 两档只在 `high` 解决不了问题时再试：官方说更高的档位不保证每张图都更好。
- 自定义尺寸的规则：宽高都是 16 的倍数，宽高比在 1:3 到 3:1 之间，单边不超过 3840，总像素在 655,360 到 8,294,400 之间，超过 3,686,400（2560×1440）算实验性。`2304x1536` 在实验线以内。

## 2. 少抽卡的办法

- 提示词整段照抄。模板和角色块是固定的，不要随手删改；要改，一次只改一处，比较结果再改下一处。
- 出图后按第 6 节的验收清单逐条对。大体对、只错一两处时不要重抽：把这张图当输入走编辑接口（`v1/images/edits`），写“只改……，其余全部保持不变”，并把不能变的东西列出来。
- 三视图定稿后就是这个角色的参考图。以后画她的任何图，都把三视图作为图 1 传进去，加上参考图块（第 3.3 节），角色块也整段原样带上。官方说 2.5 在改图和保持主体一致上比之前好，但也写明重复出现的角色仍可能走样；参考图加上重复的角色块最稳。
- 有了参考图也不能省掉或缩写角色块，改图也一样。只靠参考图，图里看不清或没画到的细节（扣子数、补丁在哪只胳膊、发夹在哪边）模型会自己补，一张张画下去就偏了；文字设定是判定对错的依据。
- 连续改图时细节还是会慢慢走样。哪一版对了，就从那一版接着改，不要在走样的版本上继续叠。

## 3. 模板

一条提示词按这个顺序拼：

1. **开头**：要画什么图、做什么用。每张图只换花括号里的部分。
2. **画风**：固定，每张图一字不改。
3. **参考图**：画三视图以外的图时加，图 1、图 2 是 `docs/design/mascots/` 里定稿的三视图。
4. **角色块**：每个角色一段固定文字（第 4 节），画谁就带谁的。
5. **构图**：按图的种类写（三视图见第 5 节，立绘见第 7 节，Q 版三视图见第 8 节）。
6. **限制**：通用的几条固定，后面接这张图自己的。

### 3.1 开头与画风（固定）

```text
请画一张{图的种类}，用作耽墨小说网站站娘“{角色名}”的官方{用途}。

【画风】日系动漫画风（anime style）的二维插画。赛璐璐上色（cel shading）：每块颜色分亮部和暗部两阶，头发和衣服的褶皱处可以再多一层更深的阴影；明暗交界是干脆的硬边，不用柔和渐变，不用厚涂、写实质感或纹理笔触。头发上的高光是一条条干脆的带状。描线较粗（bold clean outlines），清晰、流畅、闭合，外轮廓线比内部线条更粗一些；线色统一用很深的暖棕黑（#2b2228），不用纯黑。光从画面左上方照来，暗部落在画面右下的一侧。颜色干净明快，饱和度适中。
```

### 3.2 通用限制（固定）

```text
【限制】原创角色，不要像任何现有的动漫或游戏角色。画面里不要有任何文字、字母、数字、标注、箭头、色卡、签名、水印或 Logo。不要添加设定里没写的东西，包括耳环、项链、手链、手表、眼镜、帽子、美甲、纹身和多余的图案。手指数量正确，手的结构自然。
```

### 3.3 参考图（有三视图以后才加）

```text
【参考图】图 1 是{角色名}的官方三视图。它只用来确定角色的长相、发型、服装、配饰、颜色和比例：画出来的角色必须和图 1 一致，五官、比例和配色都不变，不要重新设计角色（do not redesign the character）。不要照搬图 1 的站姿、构图和背景。
```

两人同框时写“图 1 是耽耽的官方三视图，图 2 是墨姐的官方三视图”，每张参考图都说清是谁、管什么。

## 4. 角色块

块里的左右一律指角色自己的左右。外形改了，这里和设定稿一起改。

### 4.1 耽耽

```text
【角色：耽耽】
身份：现代中国的女大学生，19 岁，大二，看上去就是大学生的年纪，不要画得像初中生或小孩。家境不富裕，是个学霸，看小说看得入迷，性格天然呆。
体型：身高约 158 cm，纤细匀称，是 19 岁年轻女性的身形。正常比例下头身比约 1:6.5（日系少女比例，腿不要夸张地长）。
脸：柔和的圆脸，下巴小巧。眼睛大而圆，眼尾微微下垂，看起来有点呆萌、眼神略微放空。瞳色是琥珀棕（#a8673f），瞳孔深棕，每只眼睛两个白色高光，一大一小，都在瞳孔左上。眉毛细软，平直略向下，是比头发深的粉棕色（#c98a96）。脸颊有淡淡的粉色腮红。肤色是白里透粉的暖白。
默认表情：平静、有点出神的浅浅微笑。
头发：柔和的淡粉色（基色 #f2b6c3，暗部 #d98ea0，高光 #fde4ea），色相是略偏冷的粉，不偏橙、不偏桃色、不是三文鱼色，也不是高饱和的芭比粉；全头一个颜色，没有挑染、渐变或深色发根。中长发：长发及背，发尾到肩胛骨下沿，过肩，但比及腰的长发短得多；不是短发，也不到腰。头发披着，不扎，发丝蓬松柔软，发尾微微内扣。轻薄的空气刘海（see-through bangs），齐眉，中间略分开；脸的左右两侧各垂下一缕鬓发，到锁骨。头顶正中有一根向上翘起、弯成问号形的呆毛（ahoge）。
书签发夹：别在她自己的左侧、耳朵上方，别住一小撮侧发。发夹是一枚细长的书签：奶白色（#fbf3e6）圆角长条，约 1.2 cm 宽、4.5 cm 长，长是宽的四倍左右，明显是细长的一条，斜着别，上端朝后；书签中间印着一朵小小的粉色五瓣花（#f2b6c3）；书签下端系着一根细细的红丝带（#d0435f），垂下约 6 cm，分成两条尾巴。红丝带是她全身唯一的红色。
服装（新中式日常：现在的大学生平时会穿的新中式便服，清爽、合身、有一点文艺。是现代的衣服，不是古装或汉服，不是校服、制服，也不要宽大的童装感）：
- 外层：浅粉色（#f7e3e8）的立领针织短开衫，比头发浅得多；衣长到腰，正好盖住裙腰；前襟是三颗浅棕色（#b98a6a）圆形木扣，是纽扣，不是盘扣；下面两颗扣上，最上面一颗不扣，立领的领口敞开，露出里面白 T 恤的圆领。袖子长到手腕，袖口是罗纹，露出整只手。左手肘外侧缝着一块深梅紫色（#3d2b35）的方形补丁，补丁四周是白色的粗针脚；只有左肘有补丁，右肘没有。
- 里面：白色（#ffffff）纯棉圆领 T 恤，没有字和图案，下摆塞进裙腰里。
- 下装：深梅紫色（#3d2b35）的现代马面半裙，棉麻面料，高腰，长到小腿中部；前后各一片平整的马面，两侧是细密的褶；裙摆镶一道约 3 cm 宽的米白色（#f6f1ea）细边。素净的日常款：没有金色，没有刺绣和花纹。
- 鞋袜：白色低帮帆布鞋，白色鞋带，鞋头有一点洗不掉的灰色旧痕；白色短袜，只在鞋口露出一点。
```

### 4.2 墨姐

```text
【角色：墨姐】
身份：一本古风小说里架空王朝的少年女帝，是那本书的主角，从书里走到了现代。她是 18 岁的少女（已成年），和耽耽几乎同岁，其实还比耽耽小几个月。帅气、潇洒，有少年意气，也有帝王的威仪，是一位会用剑的少女君主。一眼就能看出是年轻的女孩：不是男人，不是雌雄莫辨的中性样子，也不是成熟的大人，没有御姐感。
体型：身高约 166 cm，比耽耽高一点。18 岁少女的身形：纤细、修长、挺拔，脖颈细长，肩膀窄，胸部含蓄，腰细。练过剑，身姿利落有力，但不要成熟丰满的身材，也不要男性化的宽肩。正常比例下头身比约 1:7。
脸：年轻少女的五官，小巧的脸，下巴尖，脸颊还带一点少女的柔和，不要成熟女人那种骨感的长脸。眼睛大而有神，比成年女子更大、更亮，是眼尾微微上挑的凤眼，上睫毛浓密纤长，眼神锐利。瞳色是墨里透紫的深灰紫（#4b4058），瞳孔更深，每只眼睛两个白色高光，一大一小，都在瞳孔左上。细长的眉毛，眉尾微微上扬，黑色。素颜感的淡妆：不画眼影，不涂浓的口红，唇色是自然的淡玫瑰色（#c98a8f）。不画花钿。肤色是偏冷的白。
```

## 5. 三视图

### 5.1 构图与限制（所有三视图共用）

```text
【构图】横版画面，同一个角色的三个全身像从左到右并排：正面、左侧面（人物面朝画面左方）、背面。三个像是同一个人在同一时刻转过身：发型、服装、配饰、颜色、比例完全一致。三个像一样大、一样高，脚底落在同一条水平线上，间距均匀，互不重叠，头顶上方和脚下都留出空白，全身完整可见，连脚一起画进去（full body visible, feet included）。站姿是放松的 A 字站姿：直立，双脚并拢，双臂自然下垂、离开身体约一拳，手掌朝向身体，看得清衣服和身体的轮廓。三个像都用角色块里的默认表情。平视，正交视角，不要透视变形，不要俯拍或仰拍。背景是纯净的浅暖灰（#f4f1ee），没有场景、地面和纹理，脚下只有一块很淡的椭圆投影。左右一律指角色自己的左右。
```

侧面画左侧，因为两人的标志物都在左边：耽耽的书签发夹、墨姐的佩剑。

三视图自己的限制，接在通用限制的后面：

```text
不要 Q 版。三个全身像之外什么都不画：没有头像特写、表情小图或道具拆解。
```

### 5.2 耽耽三视图（完整，可直接复制）

## 9. 去背

要透明背景的图先在绿幕上出（7.3），再用色键去背。生图模型自己的透明背景不一定支持，AI 抠图又容易把发丝和描线边缘抹糊，所以用色键：

- 背景色取画面四边像素的中位色，不假定正好是 #00FF00。
- 每个像素的不透明度按“绿色比红、蓝里较大的那个多出多少”来算（绿差键）：多出的不到背景的 10% 算全不透明，超过 90% 算全透明，中间按比例。角色有一圈深色描线，半透明的只有描线外侧一两个像素，不另加模糊，所以边缘利落。
- 不透明度不到 6% 的像素直接算全透明：这种像素几乎看不见，反解颜色时噪声又会被放大。画面四角偶尔有一两个像素比别处的绿幕暗，也一并清掉。
- 半透明的像素按背景色反解出原来的颜色（像素色 = 不透明度 × 原色 +（1 − 不透明度）× 背景色），再去溢色，边缘就不会发绿。
- 去溢色：绿色压到不超过“红色”与“红、蓝里较大的那个”的平均。暖色（红不少于蓝）就是绿不超过红，粉、梅紫、米白、古金都不受影响；冷色把绿压到红、蓝中间，青、青绿变成偏蓝的灰。两人身上本来没有绿色和青色，出现的都是绿幕溢色；以后画带绿色、青色的角色要先改这一条。
- 薄纱：模型常把“透过薄纱看到的绿幕”直接画成不透明的青灰、绿灰，色键分不出它的透明度，只有真正混着绿幕的那部分会变成半透明，其余的靠去溢色压回冷灰。所以墨姐立绘里的薄纱外袍基本是不透明的烟灰色；要真正透光的纱，只能在图上手工处理。
- 试过把轮廓外侧的半透明像素换成最近的不透明像素的颜色，结果更差：描线只有一两个像素宽，紧贴绿幕的那层本身混了绿，换了以后轮廓外多一圈橄榄色；往里多收几个像素再取色，又会取到头发、流苏的填充色，多一圈粉、红色晕。
- 去完放在白、黑、品红三种底色上各合成一次，放大边缘检查有没有绿边和白边；再看四边最外一圈有没有不透明的像素，有就说明角色出了画，要重抽。
