# 阅读器与内容保护

阅读器是读者待得最久的地方。它要做到三件事：

1. **无感**：换章、翻页时读者感觉不到“在加载”。
2. **舒适**：字号、行距、字体、排版、翻页方式、纸张与亮度都能按自己的习惯调。
3. **保护正文，但不妨碍阅读**：挡住大规模的自动化爬取，同时不妨碍正常的复制和读屏。

本文说明阅读器的设计与取舍。界面的视觉规则见 [设计语言](design-language.md)。

## 1. 菜单

点屏幕中间，唤出上下两栏；再点一下收起。

- **上栏**：返回、书名与章名、书签。
- **下栏**：一行进度（上一章、全书进度条、下一章），下面一行小字写这本书读了多久、今天读了多久；再下面是三个入口：**目录、背景、设置**。

底栏只放这三个入口。以后新增的阅读设置都按组接进“设置”面板，不常用的收进面板里的二级页（做法同字体列表），不再为某一类设置单独加入口。入口一多，底栏会挤，读者还要猜某一项藏在哪个入口里——比如“排版方向”既改文字方向也改翻页方向，放进哪个入口都说得通。

**设置面板**按使用频率从上往下排：字号、行距、字体、排版（横排或竖排）、翻页方式与反向翻页、段评显示，最后是这本书的自动订阅。

**目录面板**分三页：目录、书签、笔记。

在电脑上，面板不再从屏幕底部升起，而是和下栏一样宽、停在下栏上方。

## 2. 翻页

### 2.1 六种翻页方式

| 名称 | 翻页时看到什么 |
|---|---|
| 翻书 | 像纸页一样掀起来 |
| 左右平移 | 整页左右移动 |
| 上下平移 | 整页上下移动，一页一页地走 |
| 左右覆盖 | 上面一页左右移开，露出下面一页 |
| 上下覆盖 | 上面一页往上移开 |
| 滚动 | 章与章连成一条，一路往下滚 |

- 名称直接说读者看到的效果，不用“仿真”“滑动”这类说法。
- 前五种是分页模式：页眉（章名）和页脚（进度、页码）属于书页本身，跟着书页一起翻动，像真的纸页。滚动模式下页眉页脚固定不动。
- **反向翻页**：正向是横排时下一页在右边、竖排时下一页在左边（竖排书本来的方向），反向把两者倒过来。它影响所有左右方向的东西：点哪边翻下一页、滑动方向、方向键、翻书时书脊在哪一侧。

### 2.2 横排、竖排与对开

- 横排、竖排都支持。竖排时标点换成竖排的写法。
- **对开**：屏幕够宽、能放下两栏并且每栏一行至少 18 个字时，一屏是左右两页，像摊开的书；每页一行最多约 30 个字，眼睛不用走太远。翻书时以中缝为轴翻过半屏。竖排和滚动模式不对开。
- 横放的手机有刘海时，纸铺到屏幕边，字、页眉页脚、上下两栏都让开刘海，书页与中缝仍在正中。

## 3. 无感加载

读者不应该感觉到换章。

- 往后读时，提前取好后面几章；往回读时，也取好上一章。取到的章节放进缓存，只有从目录跳到很远的地方，才可能真的需要等。
- 翻过章末，直接是下一章的第一页；滚动模式一路滚进下一章。读到哪一章，地址和标题就换成哪一章，但不往浏览历史里加记录。
- 加载动画（书仰躺着翻页）只是兜底：内容确实还没到——网太慢，或者读者翻得比预取还快——而且等了超过一个很短的阈值，才出现。几乎马上就到的内容，不闪一下加载动画。
- **需要订阅的章节**：预取只取读者有权读的章节，绝不能因为预取而扣费。还没解锁的章节到了跟前，显示订阅页；这不算加载失败，不报错、不反复重试。解锁后立刻取正文接上。

## 4. 背景：纸张、配色与亮度

“背景”面板里有亮度、配色、纸张三项。它取代了早期的“夜间”开关：夜间只是配色之一（长夜）。

- **纸张**十种，从素到繁：素笺、宣纸（默认）、丝绢、洒金、花笺、落英、树影、月色、星河、猫爪。要简约优雅，不能花哨到影响阅读。
- **颜色不靠推算**：纹理只当遮罩用，每种纸在每套配色下的颜色都是逐一指定的。
- **画法按配色分组**，不是所有配色共用一种设计：
  - 浅色的六套（薛涛笺、豆青、缃叶、天青、紫藤、盐汽水）：日影、淡月、星图——浅色纸上画不出“亮”的夜空，星河画成一页古星图；
  - 墨白：墨枝（清楚的水墨，分浓淡）、烘云托月（月亮留白，四周晕淡墨云）、星图；
  - 长夜：月下枝影、夜月、银河横过的夜空。深色纸上画不出比纸更暗的影子，所以长夜的树影反过来画亮的月光，枝叶留成暗处。
- 叠上纹理后，正文的对比度仍要达标。
- **亮度**：一个滑块，也可以跟随系统。调暗时整个阅读器（包括工具栏）一起压暗，面板和提示不受影响。

## 5. 阅读字体

阅读字体只决定正文，不改界面字体。字体列表可以滚动，每一行先用这款字体本身写出它的名字，再用它写一句预览——在阅读器里预览的是读者正在读的那一句。

列表分三部分：

- **系统字体**：只有一个选项，正文用 `system-ui`，跟随设备当前的字体。不枚举、不检测设备上装了哪些字体：通用字体族在所有浏览器与 WebView 里都可用，不需要授权，也没有字体指纹的隐私问题。
- **平台字体**：精选的开源字体（目前只收 SIL OFL 1.1 授权的字体）。网页上按 unicode-range 切片加载，只下载屏幕上用到的字，所以不显示下载按钮；客户端里有下载按钮，下载完整字体后离线可用，也可以删除。中文字体动辄几兆到几十兆，所以安装包不打包阅读字体。
- **我的字体**：读者导入的 TTF、OTF、WOFF、WOFF2。只存在本机（网页存在浏览器里，客户端存在应用数据目录），不上传服务器，平台也就不承担这些字体的授权问题。Safari 可能清除很久没访问的站点数据，字体丢了会回退到默认字体并提示。

## 6. 书签、划线、想法与段评

- **位置按“第几段、段内第几个字”记**，不按页码。页码会随字号、字体、窗口大小变，段落和字的位置不会。书签在哪一页、划线落在哪几行，打开时按当前的排版算出来。
- **选择**：鼠标在正文上拖就是选（翻页靠点两侧、方向键或滚轮）；触屏长按选中一个词，接着拖动扩大范围。选中后两端有手柄。
- **工具条**：复制、划线（三种样式）、写想法、段评。点已有的划线可以看想法或删除。
- 新划线盖到旧划线时，两条合并成一条，想法接在一起，不会出现重叠的划线。
- **段评**：有段评的段落末尾有一个小气泡，写着条数；点开是这一段的评论。段末的气泡多了正文就不安静了，所以“显示段评”可以在设置里关掉。
- 划线与想法按书列在目录面板的“笔记”页。

## 7. 进度、跳回与阅读时间

- **全书进度条**：拖动途中不跳，松手才跳到那里。
- **跳回**：读者拖动进度条、点上一章或下一章、从目录、书签或笔记跳到别处后，会出现“回到第 N 章”的小签，点一下回到跳之前的位置。连跳几次，记住的仍是第一次跳之前的位置。它在读者从落点往后**净读满三页**（滚动模式约三屏）后消失，往回翻要减掉；自己翻回原来的位置时也消失。**不按时间算**：跳完章恰好放下手机很久，回来时仍然可以跳回去；往前读了一段，才说明读者确实要从这里看。
- **阅读时间**：只算真正在读的时间。阅读器在最前面、眼前是正文时起表；翻页、滚动、点按都算阅读动作，两次动作间隔不超过三分钟的那一段记进去，隔得更久说明读者走开了，不算。读了多久显示在下栏、书的详情页和“我的”里。

## 8. 订阅

- **订阅页**：锁住的章节显示本章开头作为预览，下面是订阅的范围：本章、连订十章、余下全部。余额不足时去充值。
- **预览不能变成绕过订阅的漏洞**：预览由服务端截取，按字数封顶（作者可能把一整章写成一两段，所以不按段落数）；预览接口不接受长度、起点之类的参数，同一章每次返回同一段；按账号、设备与 IP 限频。锁住章节的正文，任何接口都不下发，客户端也不能拿到全文再自己截断。
- **自动订阅本书**：只对这一本书生效，随着阅读进度自动订阅后面三章，把“提前加载后几章”的窗口延伸到订阅章节，读到订阅章节时仍然无感。跳章不触发，更不会一次订下整本书。
- 原型里的“书币”、每千字 5 书币的价格、600 的初始余额都是示例；正式的货币名称、价格、折扣与作者分成还没有定。

## 9. 正文保护

> 本节是设计，原型里还没有实现。

### 9.1 目标与边界

- 要挡的是**大规模的自动化爬取**，不是复制。复制是正式支持的功能：理论上读者可以一点点把全书复制出来，但这样的成本足以挡住批量爬虫。
- 必须保留**读屏模式**，以后还要支持 **AI 听书**。任何保护措施都不能妨碍配额内的复制和读屏。
- 截图加文字识别无法阻止。衡量效果的标准是：批量抓取变得昂贵，并且会被发现。
- 耽墨是开源项目，客户端代码谁都能看到。安全不能依赖隐藏的算法，只能依赖服务端的密钥与校验。

### 9.2 主防线在服务端

- 读正文要登录；按账号、设备、IP 限速。
- 发现异常的阅读行为：翻页快得不像人、按顺序批量拉取、无头浏览器的特征。
- 章节的访问令牌短期有效。

### 9.3 客户端只负责抬高成本

- **Canvas 绘制正文**：DOM 里没有正文文字，爬虫不能直接从页面上读。先在看不见的测量层里按同样的排版排好，得到每个字的位置，再画到每页的画布上。选择、划线、段评气泡都按这些位置计算。
- **加密传输**：章节内容加密下发，只在内存里解密。
- **内置复制**：拦下系统的复制、右键菜单与打印，改走耽墨自己的复制：要登录，由服务端校验单次字数、每日配额与频率，复制出的文字附上出处。
- **读屏模式**：改回用 DOM 渲染正文，作为无障碍的兜底。AI 听书另走一条受控的正文通道，同样要鉴权、限速。
