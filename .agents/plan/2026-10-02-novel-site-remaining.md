## 决定与理由

- **位置用"第几段、段内第几个字"（TextPoint）记**，不用页码：页码随字号、字体、窗口变。书签在哪一页、划线落在哪几行，打开时按当前排版算。段内偏移按原文的 UTF-16 码元；竖排换直角引号是一换一，偏移不变。
- **存储**：`danmo:marks`（书号 → 书签与笔记）、`danmo:my-comments`（"书号:章:段" → 我发的段评），都用 api.ts 的 localRecord（已导出），读出时逐条校验。
- **段评示例数据**在 packages/data/src/comments.ts：两本有自己试读正文的书的第一章，几段手写了贴着正文的评论；其余按散列给数，约五分之一的段落有段评（段末的气泡多了，正文就不安静了）。原型的读者是示例账号"夜读人"，发表存在本机。
- **划线不重叠**：新划线盖到旧划线时，范围并起来、想法接起来，旧的删掉（addNote 的 replaces）。
- **选择用自己的一套**，不用浏览器的原生选择：分页模式本来就禁了选择（触摸手势全给翻页），而且正文在每层页面与测量层里各有一份。鼠标在正文上拖就是选（不再拖着翻页，翻页靠点两侧、方向键、滚轮）；触屏长按 450ms 选中一个词（Intl.Segmenter）后接着拖；选中后两端有手柄。高亮用 CSS Custom Highlight API（`::highlight(rd-sel)`），不改 DOM、不影响分页。
- 段评气泡与想法记号带 `data-extra`，数字用 CSS attr() 画，元素里没有文字，数偏移时跳过；气泡 tabIndex=-1（整章都在每层页面的 DOM 里，Tab 到页外的气泡会让裁剪窗口滚动，打乱分页）。
