# 计划：顶层规划 + UI 原型（2026-09-26 起）

> 恢复检查点。继续工作前先对照当前文件与 `git log` 核实下文状态，摘要可能落后于实际进度。

## 目标（用户原话要点）

- 先做**顶层规划**（产品、架构、路线图）。
- 设计 **UI 原型**：柔和、新颖、舒适；**淡粉主色** + 多色彩主题（含**护眼**、**夜间**、其他主色）。
- 不要死板；做 **3D 书本组件**，具备多种动效，在各 UI 之间**共享平滑切换**，同时用作**加载动画**；要有想象力。
- 用户已声明：上级目录的两个旧项目（旧 monorepo 与 Figma Make 原型）已淘汰，**不作为基础**（架构差、UI 不够美、均为半成品）。

## 验收标准

1. `docs/` 下有面向人类的顶层规划（产品 / 架构 / 路线图）与设计文档（设计语言 / 3D 书本规范 / 页面交互）。
2. `prototype/` 可 `pnpm dev` 运行；浏览器中可走通：启动页 → 书架 → 详情 → 阅读器 → 返回，书本在各页之间飞行衔接。
3. 8 套主题可切换（墨晕扩散过渡），含夜间与两套护眼主题；每套主题下对比度可读。
4. Book3D 支持：静置/漂浮/悬停倾斜/拖拽翻转/开合/翻页加载/抽出等状态；加载动画复用 Book3D。
5. 移动端与桌面端布局均可用；`prefers-reduced-motion` 与应用内"动效"开关生效；键盘焦点可见。
6. `.agents/docs/` 记录实现细节；TODO 与记忆索引同步；分增量提交，里程碑打 tag。

## 关键决策（详见 docs/planning/architecture.md 与 docs/design/）

- 技术路线建议：**Web 内核（React + TS + Vite）+ 原生外壳（Tauri 2 桌面/移动）**，理由是 CJK 排版（竖排）与 3D/动效能力、唯一 UI 代码库、未来可用 ArkWeb 覆盖鸿蒙。待用户确认。
- 3D 书本用 **CSS 3D**（DOM 原生、易于共享过渡、WebView 通用），不用 WebGL；动画基于 `@property` 注册的 CSS 变量 + Web Animations API，不引入动画库。
- 设计母题：**书是主角**（一本书在各页之间旅行）；**红线**只承载信息（进度 / CP 配对 / 当前位置）；纸与墨材质，不用玻璃拟态与渐变光斑。
