# 站娘：耽耽与墨姐

**状态：设定已定稿（2026-10-02），生图提示词已写好（2026-10-03），等用户出两张三视图。** 定稿的设定在 [docs/design/mascots.md](../../docs/design/mascots.md)，提示词与外形细节在 [docs/design/mascot-prompts.md](../../docs/design/mascot-prompts.md)，那两份是权威来源，本文件不重复。本文件只记讨论里用户怎么定的、还没定的，以及插画到位后怎么接入。

## 目标

为耽墨设计两位站内角色，相当于 B 站的 22、33 或起点的点娘：吉祥物与象征，出现在启动页、加载等地方。她们首先是小说站的站娘，三站都可以用。

## 讨论中用户的决定与纠正（2026-10-02）

- 两人是一起出现的一对站娘。用户纠正过：不要把“耽”“墨”拆成读者与作者、小说站与作者站的分工。
- 三站都可以用站娘，理由是三站共用一套 UI 组件。管理站以工作为主，与娱乐的小说站定位不同，站娘浓度小一点，但作为吉祥物也能正常出现。我先前从“小说站的两个角色”推出“管理站保持合成封面”，推过头了，用户纠正了这一条。
- 墨姐的来历用第一轮提的“从书里走出来”：她是一本断更多年的古风小说里架空王朝的女帝，世界停在最要紧的那一章；全网只剩耽耽还在追更，耽耽的执念把她拉了出来。用户的理由是更贴合小说站。它取代了原先的“从古代穿越到现代”，第三轮提的“落在图书馆”那句也就不用了。
- 世界观不需要完整详细，按站娘、吉祥物的分量来。“耽耽”“墨姐”本身就是称呼，不设真名，墨姐也直接叫她“耽耽”。
- 画风取主流二次元，理由是容易传播、好画；重点是人设，画风可以变。
- 耽耽定为 19 岁、大二。我补的设定（过目不忘、先订阅再吃饭、做家教、找不到钥匙）用户接受。
- 墨姐：用户不要“夜市卖字”，但要保留“字写得好”。我补的其余几条（不看价签、领二十块、头一回看闲书、剑出不了门）用户没有删。
- 启动页保持现状（用户选的“丙”）：有主角书的页面照旧用主角书，品牌书不抢眼球，只是细节，内页算彩蛋。我推荐过的“一律用品牌书”“两本书接力”都没采用。
- 同意内页做法：画一组，每次随机翻到其中几张。
- 2026-10-03：女帝不能是配角，她是那本书的主角；“一直在找弃坑的作者”收作长线悬念，相关的悬疑剧情以后按需要再设定。
- 2026-10-03：前期出于成本用 GPT Image 2.5 出图，先出两张三视图。提示词要有基本固定的开头（画什么图、动漫画风、赛璐璐上色、较粗线条），同一套模板；设定要写得很细，避免抽卡。
- 2026-10-03：出图用 4K（3840x2160）。看过第一版三视图后：耽耽改成日常便服（第一版的开衫、小圆领衬衫、百褶裙、中筒袜像校服）；墨姐“问题最大，女性化太少，难辨雌雄”；墨姐的衣服上要有金色龙纹，剑也要有金色的装饰纹路，“当前显得太普通了”。这推翻了我原先写的“不要金色、不要龙纹”。
- 2026-10-03：看过第二版后，墨姐“太过大人的感觉，不适合面向年轻的耽墨小说网”，要和耽耽几乎同岁（设定其实稍微小一点点，但还是喊墨姐）；耽耽第二版的便服“反而不如 v1，太幼态化了”，再优化服装。第三版：墨姐定为 18 岁、比耽耽小几个月，素颜感淡妆、碎刘海、半扎高马尾、166 cm 少女身形、外袍缩到小腿；耽耽回到第一版的轮廓与配色，改成浅粉短款开衫敞开穿、白 T 恤、深梅紫高腰 A 字长裙、白帆布鞋，写明“看上去是 19 岁的大学生，不要像初中生”。设定稿里“她气场太足，耽耽初见就脱口叫了声墨姐”是我补的解释，等用户确认。
- 2026-10-03：用户要求重新设计耽耽的常服，我提了四个方向（新中式日常、泡图书馆的学霸、学姐留下的大外套、一件式衬衫裙）和两个可叠加的标志物（书本形状的斜挎包、一只粉袜一只白袜），推荐新中式加两个标志物。用户选了方向一（新中式日常），没有提两个标志物，所以没加。同时把耽耽的头发改成中长发：长发及背，比墨姐短很多，但不算太短。第四版：浅粉立领针织短开衫配深梅紫盘扣（最上面一对不扣，露出白 T 恤），素净的深梅紫棉麻马面半裙（只有裙摆一道米白细边，不用金色和刺绣，和墨姐拉开），白帆布鞋；发尾到肩胛骨。

## 没定的（不阻塞，用户想定时再补进设定稿）

- 佩剑女帝催更的梗：第一轮提过，用户没表态，没写进设定稿。
- 提示词里我补的外形细节，等用户看过第二版三视图再确认：耽耽的呆毛、书签下端的红丝带、琥珀棕的瞳色，便服的具体搭配（奶白连帽卫衣、抽绳一长一短、口袋里插着小说、浅蓝牛仔裤、左膝补丁、白帆布鞋）；墨姐的深灰紫瞳色、口红与烟紫眼影、女式高发髻、金发冠与金步摇、交领右衽、薄纱大袖外袍、马面裙与海水江崖纹、三条金龙的位置、腰封、护腕、长靴、中式直剑的样式，以及为了统一把发冠、带扣、剑的饰件等金属件全改成古金色。耽耽的帆布包与五色吧唧只放在可选的“随身物品”块里，三视图不画。
- 两人关系的官方口径（例如搭档、不官配）：第一轮提过，用户没回应。设计语言里红线表示 CP 配对，口径没定之前，品牌书和插画上不在两人之间画红线。

## 插画到位后的接入（2026-10-02 读代码确认）

- 品牌书 `BRAND_BOOK`（packages/data/src/books.ts）用在：
  - 启动页 apps/novel/app/screens/Splash.tsx 的 `hero?.book ?? BRAND_BOOK`。四个标签页里只有“我的”没有 hero。
  - 书架的下拉刷新（apps/novel/app/screens/Shelf.tsx 的 `.pull`）。
  - BookLoader（packages/design/src/book3d/BookLoader.tsx）缺省用它，但小说站正式页面里唯一的调用（阅读器切章，apps/novel/app/reader/notices.tsx）传的是正在读的书；组件实验室 Lab 的演示不算。
  - 管理站 SPA 首次打开的 HydrateFallback（apps/admin/app/root.tsx，`size={72}`）用它。三站都可以用站娘，所以站娘的画直接改在 `BRAND_BOOK` 上，管理站的加载跟着换；管理站只有这一处用到品牌书，符合“浓度小一点”。
  - 主题页的色样书（apps/novel/app/screens/Themes.tsx 的 `themeBook`）是 `...BRAND_BOOK` 换了一身配色。品牌书封面换成插画时，色样书必须照旧是纯色封面，要显式覆盖封面字段，不能跟着继承插画。
- 封面：`Book.front` 已支持图片（ImageFront），规格 800×1136 PNG（docs/design/book3d.md 第 5.2 节）。
- 内页：Book3D 的内页（`.book3d__leaf` 的两面）现在只画示意文字行，要加“内页贴图”的能力。加载状态缺省翻 5 张；启动页翻页阶段在 650~2500ms，不到两秒。每次随机挑几张，挑选要在客户端做，或者服务端与客户端用同一个种子，否则水合时内页会对不上。
- 书在这几处的宽度：启动页 148px、下拉刷新 40px。内页小画要在这么小的尺寸下认得出。
- 减少动效时启动页只显示 Logo 后淡出，看不到书；这是现有行为，不为站娘改。

## 生图（2026-10-03）

- 提示词的结构、参数与少抽卡的做法写在 docs/design/mascot-prompts.md，依据 OpenAI 的图像提示词指南（GPT Image 2.5 一栏）。两段完整的三视图提示词是用脚本核对过的：与模板各块逐字拼接的结果一致。
- 侧面画左侧，因为两人的标志物都在左边（耽耽的书签发夹、墨姐的佩剑）。改标志物的左右时，构图块的侧面要跟着改。
- 三视图定稿后作为参考图（图 1、图 2）用于以后所有的图；品牌书封面可以直接请求 800x1136，正好是封面上传的规格，也符合 GPT Image 2.5 自定义尺寸的规则。

### 三视图第一版（2026-10-03，4K）

- 出图：`gpt-image-2.5`、3840x2160、high，每张 11.2 积分、约 41 秒，返回的就是 3840x2160。之前显式写 `gpt-image-2.5-sunburst` 时两次碰到上游 429（容量用完），换别名后又碰到两次 503，都没扣积分；用户换了 API Key 的分组之后一次成功。返回的 revised_prompt 只比原文多了 32 个零宽字符，看得见的文字没变。
- 我对照验收清单看出的问题（用户随后叫停，直接给了方向）：耽耽的开衫画成了粉色而不是粉白、裙子在膝盖以上、补丁两边肘部都有；墨姐的剑柄是日本刀那样的菱形缠柄，发冠冠体是黑的。第二版的墨姐角色块顺手把剑写成了明确的中式直剑。
- 第二版提示词由 .script/update_prompts_v2.py 替换角色块与验收清单，替换后核对过完整提示词仍是模板各块的逐字拼接。

### 三视图第二版（2026-10-03，4K）

- 两张都一次成功，参数与第一版相同。图在本机 .script/output/mascots/（不提交）。
- 墨姐：一眼看得出是女性（五官、口红、女式高发髻、身形），前襟一对金龙、背后团龙、裙摆金色海水江崖纹、剑上金饰与红剑穗都画出来了；外袍缘边的回纹画成了灰色，没用金线。
- 耽耽：便服到位（奶白卫衣、口袋里的粉色小说、卷边牛仔裤、只有左膝有补丁、白帆布鞋）；两根抽绳几乎一样长；背面图里红丝带画到了她的右侧，与正面、侧面对不上。

### 三视图第三版（2026-10-03，4K）

- 两张都一次成功，参数不变，图在本机 .script/output/mascots/（不提交）。
- 耽耽：浅粉短款开衫敞开、白 T 恤、深梅紫高腰长裙、白帆布鞋，像大学生，不再幼态；补丁只在左肘，三个视图都对上了。
- 墨姐：明显年轻了（碎刘海、半扎高马尾、淡妆、少女的脸），仍看得出是女性；外袍缘边的回纹这次是金色；黑底金龙、中式直剑和红剑穗都在。
