耽墨的界面方向由用户确立，并在看过原型后认可（"UI我看到了，非常不错"）：柔和、新颖、看着舒适；淡粉为默认主色，同时提供多套主题（护眼、夜间与其他主色）；设计不要死板，要有想象力和创造力；3D 书本组件要有多种动效、在各页面之间共享平滑切换，并复用为加载动画。

原型（基线提交 15d7bba）落实为以下母题，后续界面沿用：

- **书是主角**：同一个 CSS 3D 书本（Book3D）在页面之间飞行衔接；进入阅读器时书打开并推进到铺满屏幕；加载动画也是这本书在翻页。
- **红线只承载信息**：阅读进度、CP 配对、当前位置、焦点环。不作装饰。
- **纸与墨材质**：纸色底加纸纹，墨色正文（不用纯黑），阴影随主题染色。不用玻璃拟态、渐变光斑、满屏粒子。
- **动效回应操作**：非用户触发的循环动效只给每屏一本主角书；必须尊重"减少动效"（系统设置与应用内开关）。
- **安静，少说明**：不在物件旁边写操作说明（例如曾经放在书下面的"翻到封底看简介 / 翻回封面"），让物件本身可以直接上手（点一下书就翻面，拖动照旧）；键盘与读屏用户靠不可见的可访问名称补上操作入口。装饰性的写实细节要克制，比例参照真书（封底书号条码只占封底宽度的四分之一左右）。
- **8 套主题**：薛涛笺（默认淡粉）、长夜（夜间）、豆青与缃叶（护眼）、天青、紫藤、盐汽水、墨白。
- **字体**：霞鹜文楷屏幕版（标题与正文）加系统无衬线（控件）；马善政毛笔楷书只用于 Logo 与线装题签；思源宋体用于现代封面标题与阅读字体选项。均为 SIL OFL 1.1。

**Why:** 用户的原始需求明确要求淡粉主色、多主题、3D 书本共享切换与加载动画，并对原型给出正面评价。这些母题是让界面区别于模板化"粉色阅读 App"的关键，丢掉任何一条都会削弱辨识度。

**How to apply:** 新界面沿用上述母题与设计令牌（packages/design/src/styles/tokens.css、themes.css）。作者站与管理站使用同一套母题（用户 2026-09-27 要求三站"使用相同设计风格"，见 [[multi-site-deployment]]）；每个页面都要分别设计移动端与电脑端布局（见 [[responsive-layouts]]）。新增主题必须补全 themes.css 头部注释列出的全部变量，并通过仓库根目录的 `pnpm check:contrast`。新增"红线"用法前先确认它编码了信息。想加一行操作提示时，先想办法让操作本身不言自明。阅读页的纸张、亮度与配色见 [[reading-backgrounds]]，各标签页放什么见 [[tab-roles]]。面向人的正式文档是 [设计语言](../../docs/design/design-language.md)（2026-10-02 写成，含令牌、主题、层级表）：改令牌、主题、层级时同步改它，两处说法不一致时以用户的原话（本条 Evidence）为准、再修正文档。

**Evidence:** 用户 2026-09-26 原始需求；用户 2026-09-27 原话"UI我看到了，非常不错"；提交 15d7bba；对比度脚本 2026-09-26 运行结果为 8 套主题全部达标。"安静，少说明"一条来自用户 2026-09-27 的两次纠正："去掉或优化书本3d模型下面的`翻到封底看简介` `翻回封面`，这是非常难听冗长的两句话，换个描述，或者改成点击模型自动翻（同时保留当前已有的可拖动翻页……需要区分点击一下和手动拖）"；随后"当前条形码和文字都太大了，至少需要缩小一倍。其次我提过的翻到封底看简介、翻回封面这个还是没有去掉或者修改，这两串文字很突兀，不够和谐"。

**Recheck when:** 用户提出新的视觉方向；docs/design/design-language.md 与本条的母题出现分歧时。
