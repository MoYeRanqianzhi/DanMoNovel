**用户的要求（2026-09-27）**
- 阅读字体不止三种。选择方式改成可滚动的列表，每种字体都有文字预览。
- 非 Web 端（桌面、移动客户端）每种字体配下载按钮。安装包默认不打包字体，因为中文字体太大。
- 允许使用设备上已安装的系统字体。
- 允许导入额外的字体文件。导入的字体只在本地使用，不上传服务器；Web 端也存在浏览器里。
- 同日纠正：系统字体直接用 `sans-serif`、`system-ui` 这类通用字体族设置，不需要列出设备上的每一款字体。

**方案（我的判断，用户尚未逐条确认）**
- 列表由三部分组成：一个"系统字体"选项、平台字体（精选的开源字体，由平台的字体服务提供）、我的字体（导入的）。每行先用这款字体本身写出字体名，再给一行预览。在阅读器里预览读者正在读的那一句，其他地方用固定的示例句。
- Web 端：平台字体用按 unicode-range 切片的网页字体。浏览器只下载屏幕上用到的字所在的分片，并自行缓存，所以不显示下载按钮，只在首次使用时显示加载状态。
- 客户端：显示字体大小与下载按钮，把完整字体文件下载到应用数据目录，离线可用，也可以删除以释放空间。未下载的字体，在线时预览用分片网页字体（只取预览句用到的字），离线时用预先渲染好的预览图。
- 系统字体：只有一个选项，正文字体设为 `system-ui, sans-serif`，跟随设备当前使用的字体。用户在手机设置里换了字体，阅读器也随之改变；这一点在 Android 与鸿蒙上还要用真机验证。不枚举、也不检测已安装的字体，因为：`system-ui` 在所有目标浏览器与 WebView 中都可用，不需要授权、不需要下载，也没有字体指纹的隐私问题；而枚举接口只有桌面 Chromium 支持，Safari 的网页本来就看不到用户安装的字体。想用某一款特定字体的读者，用"导入字体"。
- 导入字体：接受 TTF、OTF、WOFF、WOFF2。Web 端存进 IndexedDB 并申请持久化存储；客户端存进应用数据目录。字体名从文件的 name 表读出，用户可以改名。用到时才用 FontFace 注册。
- 设置同步只同步"选了哪一款字体"。换到没有这款字体的设备时，回退到默认字体并提示用户。
- 三种来源最终都成为页面可用的字体族，因此同样适用于 Canvas 绘制正文（见 [[content-protection-goal]]）；绘制前要先调用 `document.fonts.load()`。
- 这份列表只决定正文字体，不改界面字体。

**界面字体（用户 2026-09-27 确认保持现方案）**
- 界面用的霞鹜文楷屏幕阅读版、马善政楷书、思源宋体（400/700），以按 unicode-range 切片的网页字体随前端构建发布，浏览器只下载页面上用到的分片。客户端直接用同一份前端构建。
- 2026-09-27 实测小说站构建产物：WOFF2 分片 380 个，共约 16MB（文楷 5.1MB、马善政 3.6MB、思源宋体 6.5MB），另有约 12MB 的 WOFF 回退文件。打包客户端时可以去掉 WOFF 文件，因为目标 WebView 都支持 WOFF2（打包前再核实）。

**Why:** 一款中文字体动辄数 MB 到数十 MB，全部打包会让安装包体积失控；Web 端的切片加载本来就是按需的，再放下载按钮没有意义。导入的字体只在本机使用、平台不分发，平台也就不必承担这些字体的授权问题。

**How to apply:**
- 平台字库目前只收 SIL OFL 1.1 字体，每一款都记录许可与来源。霞鹜新致宋、新晰黑、铭心宋是 IPA 许可，要先确认子集化与改名的条件；京華老宋体、汇文明朝体的许可不清楚，不收录。
- 任何一种来源都要能优雅退化：离线、用户未授权、浏览器不支持相关接口时，列表依然可用。
- 系统字体用通用字体族实现，不做检测或枚举（用户 2026-09-27 的纠正）。`ui-serif`、`ui-rounded` 等关键字只有 Safari 支持，不能作为跨平台选项。
- Safari 可能清除 7 天内没访问过的站点的 IndexedDB，导入的字体可能随之消失；导入时要提示，并在字体丢失时回退。
- 导入字体合集（TTC）时拆出单款字体再注册。
- 字体许可、字体包、浏览器与 Tauri 能力的出处见 [[font-platform-facts]]，其余平台事实见 [[platform-support-facts]]。

**Evidence:** 用户 2026-09-27 原话："字体选择不止三个，所以形式改成可滚动列表，并且文字有预览，对于非web端还要有下载按钮（不能默认把字体打包进去，太大了），同时允许用户使用自己的系统字体、允许额外上传字体（注意不是上传服务器，而是在本地使用，web端也需要放在浏览器里而非在服务器上）"；同日纠正："系统字体应该是直接设置sanif/system-font之类的，你想想是不是这样"；同日答复待确认问题："界面自身字体还是保留现在的方案"。

**Recheck when:** 用户调整字体来源或客户端打包策略时；界面字体方案或客户端包体积的要求变化时；相关浏览器接口的支持情况发生变化时。
